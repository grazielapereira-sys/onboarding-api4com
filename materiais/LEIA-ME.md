# Materiais em PDF

Esta pasta guarda os documentos que a pessoa abre direto do onboarding, sem
precisar de login — ao contrário das páginas do Confluence, que exigem acesso
que o recém-chegado ainda não tem.

## Como colocar um PDF aqui

1. No Confluence, abra a página e use **... (três pontos) → Exportar → PDF**.
2. Salve o arquivo nesta pasta com o nome exato da tabela abaixo.
3. Me avise — eu aponto o botão do onboarding para ele.
4. Na hora de publicar, suba a pasta `materiais` junto com o `index.html`.

## Nomes esperados

| arquivo | de onde vem | onde aparece |
|---|---|---|
| `beneficios.pdf` | página de benefícios no Confluence | botão "Mais sobre os benefícios", no bloco Nossos benefícios |
| `equipamentos.pdf` | página de equipamentos no Confluence | botão "Mais sobre equipamentos", no slide de setup |
| `conteudos-rh.pdf` | conteúdos do RH para o time | tarefa "Conheça os conteúdos do RH", no bloco Quem somos |

Use sempre letras minúsculas e sem acento no nome do arquivo: o servidor
diferencia maiúscula de minúscula, o Windows não.

## Importante

O site é público — quem souber o endereço do arquivo consegue abrir, mesmo sem
o link individual. Não coloque aqui nada que não possa sair da empresa.
